# Emmanuel Zúñiga Castro — Resume

Online resume set as a design annual's plate page: one grotesque, hairline rules,
a periwinkle seal and a live halftone screen in the background that reacts to the mouse.
Print / "Save as PDF" produces a clean A4 resume.

Built with plain HTML, CSS, and JavaScript — no frameworks, no build step.

## Files

| File | Purpose |
|------|---------|
| `index.html` | Page content |
| `styles.css` | Layout, type, print styles |
| `script.js` | Print button, section highlight, halftone background animation |
| `CV_Emmanuel_Zuniga.docx` | CV served by the "Download CV" button |

## Run locally

Open `index.html` in a browser, or serve it:

```bash
python -m http.server 8080
# then open http://localhost:8080
```

## Deploy

GitHub Pages serves the `main` branch root. Push to `main` and the site updates in about a minute.
